# Minimal Launcher

텍스트 중심의 안드로이드 홈 런처 MVP.

## 핵심 컨셉
- 홈 화면은 **미니멀 위젯 스타일 정보 뷰**(시간/날씨/오늘 할 일)
- 제스처 기반 빠른 이동
  - 좌: 전화
  - 우: 메시지
  - 위: 앱 목록
  - 길게 누르기: 런처 설정
- 앱 목록은 **아이콘 없이 텍스트 리스트**
- 앱 이름 커스텀/숨김 지원

## 현재 기능
1. HOME/DEFAULT 인텐트 등록 (기본 런처 선택 가능)
2. 홈 화면 제스처 네비게이션
3. 앱 목록 텍스트 런처
4. 설정 화면
   - 지역/관심사/할 일
   - 라이트/다크, 폰트 사이즈
   - 앱 숨김/숨김해제
   - 앱 표시 이름 커스텀(alias)

## 실행 방법
1. Android Studio에서 `Minimal Launcher` 폴더 열기
2. Gradle sync
3. 디바이스 연결 후 Run (`app`)
4. 홈 버튼 누르면 기본 홈 앱 선택창에서 `Minimal Launcher` 선택

## 비고
- 아래 스와이프(알림/퀵세팅), 시스템 제스처는 OS 기본 동작 우선
- 앱 목록은 `ACTION_MAIN + CATEGORY_LAUNCHER` 앱 기준으로 구성
- 앱 이름/숨김 설정은 DataStore에 저장됨
